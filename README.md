## ⚙️ Installation

Clone the repository:

```bash id="r7k3p1"
git clone https://github.com/sandovaleloy/PORTAFOLIO_ELOY.git
```

Navigate to the project:

```bash id="w5m9qd"
cd PORTAFOLIO_ELOY
```

Install dependencies:

```bash id="x2v6la"
npm install
```

Start the development server:

```bash id="c4h8zs"
npm run dev
```

The application will be available at the local address provided by Vite.
